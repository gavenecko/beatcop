# BEAT COP: Donut Justice
Top-down pixel-art beat cop game. Play: https://gavenecko.github.io/beatcop/

Touch: left side = joystick · A act (tackle/cuff/donut/clue/solve) · B car in/out · RUN sprint · 🚨 siren · II pause

Keys: WASD/Arrows · Space/J act · E/K car · Shift sprint · H siren · P/Esc pause
